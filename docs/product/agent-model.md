# Agent 模型

**版本**: v0.1
**最后更新**: 2026-08-02

## 1. Agent 身份

每个 Agent 拥有跨越小镇生命周期的稳定身份：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 唯一、永久标识符 |
| name | string | 显示名称 |
| role | enum | 长者、铁匠、木匠、采集者、侦察兵、商人、教师、农夫、讲故事者、玩家 |
| traits | string[] | 性格标签：好奇、谨慎、社交、懒惰、雄心勃勃等 |
| skills | map<string,int> | 技能名->等级 |

## 2. Agent 状态

每个 tick 变化的动态状态：

| 字段 | 类型 | 说明 |
|------|------|------|
| energy | float (0-100) | 被动作消耗；睡眠/休息恢复 |
| mood | enum | 开心、平静、焦虑、愤怒、悲伤 |
| gold | int | 交易货币 |
| location | LocationID | 当前在地图上的位置 |
| currentTask | *Task | 当前正在做的事情 |
| inventory | []Item | 携带的物品 |
| socialTies | map<UUID,float> | 与其他Agent的关系强度（-1.0 到 1.0） |

## 3. 记忆系统

### 3.1 短期记忆
- Agent 最近直接观察到的 N 个事件（默认 N=20）。
- 保存当天的原始观察记录。
- 用于即时决策。

### 3.2 长期记忆
- 压缩存储的事件，每条为一个 MemoryEntry。
- 重要事件在"休息"tick 期间从短期记忆整合到长期记忆。
- 长期记忆可按语义相似性检索（未来通过向量数据库）。

### 3.3 日记
- 每个 Agent 维护每日日记：一天的压缩摘要。
- 其他Agent可以阅读（如果分享）或玩家可以阅读。

## 4. 目标

Agent 拥有层次化目标：

1. **生存目标**（始终激活）：维持体力、食物、安全。
2. **角色目标**（由原型驱动）：如铁匠每天制作3件物品。
3. **社会目标**（源于关系）：拜访朋友、解决冲突。
4. **知识目标**（可选）：学习特定声明、调查神秘事件。

每个 tick 的目标选择使用效用评分系统。最高分且可行的目标成为 Agent 当前任务。

## 5. 行为策略

### 决策流程（每个tick）
1. **观察**：收集当前地点的事件。
2. **更新信念**：将观察处理为 KnowledgeClaim 和 MemoryEntry。
3. **评估目标**：对所有活跃目标评分。
4. **选择行动**：执行最高分行动。
5. **记录**：在事件日志中记录决策、行动和结果。

### 日常日程

| 时间段 | 典型活动 |
|--------|---------|
| 06:00-08:00 | 起床、早晨例行 |
| 08:00-12:00 | 主要工作（角色任务） |
| 12:00-13:00 | 午间休息（广场） |
| 13:00-17:00 | 次要工作或探索 |
| 17:00-19:00 | 社交时间（广场） |
| 19:00-21:00 | 休闲/写日记/休息 |
| 21:00-06:00 | 睡眠 |

日程是软约束。Agent 可能在紧急目标时跳过社交时间。

# K-town Agent 模型设计

## 1. Agent 核心属性
每个Agent包含以下核心模块：

### 1.1 身份（Identity）
- **id**：唯一标识符
- **name**：姓名
- **role**：职业，决定工作类型和技能
- **traits**：性格特质列表，影响决策倾向
- **skills**：技能等级字典，影响工作效率

### 1.2 状态（State）
- **energy**：体力值，0-100，影响工作能力
- **mood**：心情状态，影响社交意愿
- **gold**：金币数量，用于交易
- **location**：当前所在位置
- **current_task**：当前正在执行的任务
- **inventory**：背包中的物品
- **social_ties**：与其他Agent的好感度字典

### 1.3 记忆（Memory）
- **short_term**：短期记忆，保存最近20条事件，超过则压缩为长期记忆
- **long_term**：长期记忆，保存重要的历史事件
- **diary**：个人日记，记录每天的重要经历

### 1.4 目标（Goals）
- **description**：目标描述
- **base_priority**：基础优先级
- **urgency**：紧急程度
- **completed**：是否已完成

## 2. 行为决策流程
每个Tick，Agent按以下流程行动：
1. **感知**：收集当前位置的事件和人物
2. **思考**：更新状态、处理记忆、评估目标
3. **决策**：根据当前状态选择行动
4. **行动**：执行行动，更新状态

## 4. 心情系统
Agent的心情受以下因素影响：
- 体力值低于20：心情变为悲伤
- 体力值低于50：心情变为焦虑
- 体力值高于80：心情变为开心
- 成功完成目标：心情提升
- 社交互动成功：心情提升
- 遇到危险事件：心情下降

## 5. 社交系统
- 两个Agent在同一地点相遇时，有概率进行社交
- 社交成功：双方好感度+1，可能传播知识
- 社交失败：双方好感度-1
- 好感度大于5：成为朋友，社交成功率提升

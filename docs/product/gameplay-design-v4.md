# K-town 玩法设计 v4.0 —— 让小镇活过来，也让你住进去

> **状态**：权威设计（取代 v3）
> **日期**：2026-08-20
> **视角**：游戏大师（承接 v3 评审结论 + 作者初心"有自我意识的小镇"）
> **配套**：美术见 `art-direction-v1.md`；实现安排见 `design-master-plan-2026-08-04.md` Phase 6-9
> **世界观基底**：`世界观/` 五篇（末世重建、20 小时制、失忆旅行者）

---

## 0. 一句话与三支柱

**K-town 是一座有自己生活的边境小镇。你走进来，看它活着，成为一个居民，然后——你的一个习惯改变了这座小镇。**

三支柱（继承 v3）：**见证 / 归属 / 惊奇**。

**v4 新增"游戏感三件套"**，把"观察型小镇"从"好看的水族箱"变成"有呼吸的游戏"：

| 三件套 | 回答"游戏感在哪" | 对应章节 |
|---|---|---|
| **情绪闭环** | 居民会沮丧、会改变、会成长——你看到"因为所以" | §3（灵魂） |
| **危机与干预** | 小镇会出事，你的选择改变结局 | §4 |
| **长期目标线** | 你有一个"为什么留下来"的理由（重建 + 身世） | §5 |

## 1. 核心循环

### 1.1 世界的循环（始终在运行，游戏的心脏）

```
时间推进 → 事件发生 → Agent 感知 → 思考 → 决策 → 执行动作 → 世界变化
   ↑                                                           ↓
   └──── 情绪 ↔ 行为 ↔ 学习（习惯）↔ 性格演化 ← 行动后果 ←─────┘
```

**v4 关键升级**：v3 的循环是"感知→决策→行动→世界变化"，v4 把**情绪、学习、性格演化**接进环里——这正是作者初心的核心（"人会因为自己的行为学到东西，性格做出改变"）。

### 1.2 玩家的循环（每日）

```
醒来 → 读小镇脉搏（谁在哪/谁不开心/在传什么/今天什么天气）
     → 用 12 AP 行动（移动/工作/交谈/调查/休息/添知识）
     → 傍晚广场汇集 → 夜晚入睡
     → 读日报：今天小镇发生了什么、为什么
     → 【v4 新增】随时介入：危机来袭时选择帮忙/调查/澄清/旁观
     → 【v4 新增】长期目标进度：重建小镇 / 收集身世碎片
```

玩家仍与 NPC 走同一条动作管线（`tick._handle_action`），是平等的一员，不是 GM。

## 2. 五大系统（v3 保留 + 修订）

> 原则不变：五个系统共享同一个"感知→决策→行动"反馈环。

### 2.1 时间与节律（保留 v3）

一天 = 20 小时（大缓变后地球转速变慢），清醒 12h + 睡眠 8h，清晨 5 点醒。回合制，1 AP = 1 小时，休息 = 入睡跳天。

### 2.2 关系（保留 v3）

双向好感 `social_ties`，按等级门控对话/交易/分享/影响决策。关系产生可见行为（好友并肩、宿敌回避），派系 = 聚类结果。

### 2.3 知识（保留 v3，K-town 招牌）

KnowledgeClaim 结构化知识，传播/质疑/固化。**v4 补充**：知识不再只是"信息"，而是**情绪与习惯的输入**——"听说矿价大涨"会兴奋（愉悦↑）并更可能去采矿（习惯强化）。知识、情绪、行为三者互相咬合。

### 2.4 经济（v3 保留 + 修复半成品）

- 保留：生产→消费→交易→再投资，价格随供需波动驱动行为，金币回收防通胀。
- **修复**：NPC 响应交易（现在是发起无人接）、物品有真实用途（制作→工具→效率）、价格真正接入决策（现在 Agent 买食物用硬编码价而非 `world.get_price`）。
- **v4 接入情绪**：缺钱焦虑（焦虑↑）→ 更拼命工作（习惯形成）；物价飞涨愤怒（愤怒↑）→ 可能闹事或逃离。

### 2.5 情绪 —— "天气"的可见化（v3 保留 + 升级为 §3 灵魂系统）

v3 已有：心情波动、地图情绪光环、事件响应人格化、情绪传染。
v4 把情绪从"展示层"升级为"驱动层"：**情绪不只是颜色，而是行为的因**。

## 3. 情绪系统 v2 —— 让居民"会因行为而改变"（灵魂章节）

> 对应初心：*"被老师骂了，你感觉很沮丧，暗自决定下次一定不能再这样。敏感的人冲击大、决定极端；大大咧咧的人无所谓、改变温和。"*

### 3.1 模型：从 Mood 5 档 → 多维情绪

| 项 | v3 现状 | v4 设计 |
|---|---|---|
| 结构 | 单一 `mood` 5 档（happy/neutral/sad/angry/anxious） | **4 维情绪**：愉悦 / 焦虑 / 愤怒 / 悲伤，各 0-100 强度 |
| 呈现 | 地图表情 emoji | 地图表情（emoji）由**主导情绪**决定；光环颜色由主导情绪决定（继承 v3 色板） |
| 存储 | mood 字段 | agent.emotions {joy, anxiety, anger, sadness} |

**为什么要多维**：初心说"不同性格的人心情值系统完全不同"。单一 mood 无法表达"一个又愤怒又悲伤的人"或"表面平静但焦虑极高"——多维才能支撑性格差异化的情绪反应。

### 3.2 事件 × 性格 → 情绪偏移（"同一事件，不同反应"）

每个事件对情绪有一个**基础偏移**，再被性格调制：

```
情绪偏移 = 事件基础偏移 × 性格调制系数 × 关系调制
```

**性格调制系数**（性格 5 维：尽责/开放/外向/亲和/稳定）：

| 事件 | 基础偏移 | 敏感者（稳定低） | 大大咧咧（稳定高） |
|---|---|---|---|
| 被批评 | 悲伤+20 | 悲伤×1.8（冲击大） | 悲伤×0.5（无所谓） |
| 工作成功 | 愉悦+15 | 愉悦×1.3 | 愉悦×0.8 |
| 听说矿价大涨 | 焦虑-10, 愉悦+5 | 焦虑×1.5 | 愉悦×1.2 |
| 灾害 | 焦虑+30, 悲伤+10 | 焦虑×2.0 | 焦虑×0.7 |

> **实现**：查表 + 乘法，规则引擎即可，与现有 5 层决策契合；**不做真 RL 训练**（初心"近似强化学习"是机制形状：行为→反馈→概率更新，见 §3.4）。

### 3.3 情绪 → 决策渗透（"心情影响行为"）

情绪进入 `decide()` 各层，而不是只做展示：

| 情绪主导 | 决策倾向 |
|---|---|
| 高焦虑 | 更倾向"调查/避险"（核实传闻、回家），回避高风险行动 |
| 高愉悦 | 更倾向社交、主动分享知识 |
| 高愤怒 | 更可能冲突、拒绝帮助、工作效率↑但关系↓ |
| 高悲伤 | 行动力↓、独处倾向、工作效率↓ |

**性格调制**：同样高愤怒，亲和高者压住怒气（行为温和），稳定低者爆发（行为极端）。

### 3.4 情绪记忆 → 习惯形成（近似 RL，初心灵魂）

**这是 v4 最核心的新机制。**

```
行为 → 情绪反馈（正/负） → 该"情境→行为"对的出现概率更新 → 重复 → 固化为习惯 → 性格演化
```

- **情境** = 关键状态组合（如"早上 6 点 + 工作"、"下雨 + 在外"、"被批评 + 同一件事"）。
- **行为** = Agent 在该情境下的选择（如"提早出门"、"带伞"、"不再迟到"）。
- **情绪反馈** = 行为后的情绪变化（做对了愉悦↑，做错了焦虑/悲伤↑）。
- **概率表更新** = 每个 Agent 维护一张"情境→行为→出现概率"小表（本地，非全局），行为带来正反馈则概率↑，负反馈则↓。

**示例（呼应初心"上课迟到被骂"）**：

```
情境{早上, 要去工坊} → 行为[准时出门] → 全勤 → 愉悦+15 → 概率 +8%
                       行为[赖床迟到] → 被批评 → 悲伤+25 → 概率 -12%
→ 重复几天后，"准时出门"成为习惯，不再需要思考
```

**性格演化**（初心"性格做出改变"）：

- 习惯反复触发（阈值，如同情境同行为累计 7 次）→ 对应性格维度微调（如尽责 +1）。
- 极端情绪事件（如被骂时悲伤×1.8）→ 该情境的习惯形成速度×2（敏感者改变剧烈）。
- 性格演化是**慢速**的（上限 ±2/月），且受稳定性调制（稳定高者性格不易变——大大咧咧永远大大咧咧，但因此也更难成长）。

### 3.5 情绪传染（继承 v3）

情绪在人群间传染，稳定高者抗传染。**v4 补充**：传染不是随机扩散，而是走关系网——好友之间的情绪传染率 > 陌生人。危机时的恐慌是"沿着关系链扩散"的，玩家能看到恐慌从一个人传到一条街。

### 3.6 验收（可测）

- [ ] 日志可复现全链：`被批评 → 悲伤↑（敏感者×1.8）→ 次日行动改变（提早出门）→ 愉悦↑ → 习惯概率表更新`
- [ ] 同一事件，两个性格相反 Agent 的情绪偏移不同、后续行为不同
- [ ] 习惯形成后可观察到"不再需要 LLM/随机，稳定选择"
- [ ] 性格维度可随习惯缓慢演化（阈值触发），且在档案中可见

## 4. 危机事件与玩家干预 —— "小镇会出事，你能伸手"

### 4.1 危机类型

| 危机 | 触发 | NPC 反应（性格矩阵） | 玩家干预 |
|---|---|---|---|
| **灾害**（暴风雨/塌方） | 天气链/事件链 | 尽责者组织、外向者呼救、高焦虑者逃 | 帮忙（AP 换进度）、旁观 |
| **疫病**（旧世界病） | 低概率事件 | 亲和者照顾、稳定低者恐慌传染、独居者隔离 | 调查（找药）、澄清（辟谣） |
| **谣言风暴**（传闻失控） | 知识冲突堆积 | 高开放者探究、高神经质者全信、智者辟谣 | 澄清（注入正确知识） |
| **资源危机**（食物短缺） | 经济失衡 | 农民多种、商人囤积、穷人出走 | 帮忙（提供资源） |

### 4.2 玩家干预模型

- 危机持续 N 天（有倒计时，制造紧张感）。
- 玩家每日可投 AP 干预：**帮忙 / 调查 / 澄清 / 旁观**（各 AP 不同）。
- **结局分支**：干预充分 → 危机缓解（关系↑、小镇声望↑、居民记住你）；旁观/失败 → 危机恶化（关系↓、有人受伤/离开、小镇倒退）。
- **性格化反应**：NPC 对玩家干预的反应也看性格——你帮忙，亲和者感激（关系+8），高焦虑者怀疑（关系+2）。

> **原则**：危机是"小镇自己的事"，玩家是"伸手的人"不是"救世主"。干预成功是锦上添花，不是必须；但旁观有真实代价。

## 5. 长期目标线 —— "为什么留下来"

### 5.1 小镇重建弧线（复用现有 `location_levels`）

```
资源（采集/制作） → 修缮建筑（AP + 资源） → 解锁新地点/新功能 → 升级
```

- 已有雏形：`world.location_levels`、小镇升级逻辑、`location_levels` 前端显示。
- **v4 完整化**：每条升级链有可见进度（"工坊从残破到兴旺"），升级解锁内容（新制作配方/新事件/新居民来访）。
- **情绪联动**：修缮让居民愉悦↑（家园感），危机让修缮进度倒退（损失感）。

### 5.2 身世之谜（接通现有伏笔）

- 现有：失忆旅行者（玩家）+ 古玉佩"十三时" + 夜间探索（`_night_mystery`）+ 末世遗迹。
- **v4 完整化**：玩家收集身世碎片（夜间探索/调查/对话解锁），集齐 N 片解锁主线线索（大缓变真相的片段）。
- **知识联动**：碎片本质是"旧世界知识"，玩家可分享给居民 → 居民产生新知识 → 可能改变小镇。

## 6. 事件系统 v2

- 保留：14 种 EventType + 每日调度 + 事件链 4 种。
- **v4 升级**：
  - 危机类事件（§4）加入调度，**玩家可参与**（不再只播报+状态微调）。
  - 事件的情绪偏移（§3.2）接入：每个事件带基础情绪偏移表。
  - 事件的归宿仍是决策（事件→感知→决策→行动→世界变化），但情绪是中间放大器。

## 7. 数值与平衡（收敛到可调）

| 项 | 值 | 说明 |
|---|---|---|
| 情绪 4 维 | 0-100，初始 40-60 | 每 tick 向基线回归（速率 = 稳定性调制） |
| 性格调制系数 | 0.5 ~ 2.0 | 查表（§3.2） |
| 习惯学习率 | 单次 +5%~-10%，上限 90% | 情境→行为→概率表 |
| 习惯固化阈值 | 同情境同行为累计 7 次 | 触发性格维度 +1 |
| 性格演化上限 | ±2/月 | 慢速，稳定性高者更低 |
| 情绪传染 | 沿关系网，好友 > 陌生人 | 稳定高者抗传染 |
| 危机持续 | 3-5 天 | 有倒计时 |
| 干预 AP | 帮忙 3 / 调查 2 / 澄清 1 / 旁观 0 | 玩家每日 12 AP 内决策 |

> 全部数值收敛到 `config.py`/参数常量；**每个数值必须有可见原因**（日报/档案解释"为什么变了"）。

## 8. 明确不做什么（Non-goals，继承 v3 + 新增）

- ❌ 不做玩家英雄成长线（技能树/声望/排行榜）——玩家是居民，不是英雄。
- ❌ 不做脚本化剧情——叙事 = 涌现 + 事后总结。
- ❌ 不做多玩家/大规模（>20 Agent）。
- ❌ 不做复杂生产链（星露谷式）——先做一条食物闭环。
- ❌ **不做真 RL 训练**（初心"近似强化学习"是机制形状：行为→反馈→概率更新，不是真训练网络）。
- ❌ **不做成就系统**（现有 achievements 恒空，删除或后置）。

## 10. 设计原则（评审对照）

1. **一条闭环，做到可见** —— 任何新系统必须挂到"感知→决策→行动→世界变化"上，v4 加"情绪/学习/性格"。
2. **每个数字有可见原因** —— 世界不沉默，日报/档案/事件流解释为什么。
3. **深度优先于广度** —— 3 个接线良好的系统 > 10 个冻结的。
4. **玩家读小镇，不读 HUD** —— 信息架构是核心系统。
5. **玩家是居民，不是 GM** —— 玩家与 NPC 走同一条动作管线。
6. **先观察，后加入** —— 新手引导的第一个动作是"点一个居民，看他是谁"。
7. **情绪是行为的因，不是装饰** —— 没有情绪驱动的行为，就没有"活着"的小镇。

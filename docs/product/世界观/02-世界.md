# 世界

很久以前，发生了一场大缓变。

没有人确切知道它是怎么开始的。有人说是天上的事，有人说是地下的反，也有人觉得世界本来就是这样，只是忽然换了一种走法。留下来的记录太少，说法太多，谁也说服不了谁。

大缓变之后，地球转得慢了。一天只有二十个小时——白昼十二个，黑夜八个。

听起来差别不大，但日子确实不一样了。白天变得更长，太阳挂在天上迟迟不落，干活的时间多了，可人也更容易累。黑夜变短了，却也更沉。入夜之后，外面会变得危险。没人说得清具体是什么危险，但居民们都知道规矩：天黑就锁门，别出去。

旧世界留下来了些东西。

城市、公路、工厂，都成了废墟，散落在荒野里。有些还立着，大部分已经塌了，被土和草盖住大半。偶尔有人在废墟里翻到还能用的物件——金属片、齿轮、工具、书页。这些东西成了镇上的宝贝。旧世界的知识也留下了一些，零零碎碎的，靠口口相传和偶尔翻到的记录拼凑着。

大缓变的原因，没有人知道。

也许藏在某座废墟的深处，也许写在某一页没人读得懂的书里。也许有一天会有人发现，也许永远不会。居民们更关心明天吃什么、工坊能不能出活、矿洞还安不安全。世界怎么变成这样的，是活着的人没空细想的事。

# K-town 产品愿景 PRD

## 1. 项目目标
构建一个多智能体小镇模拟系统，开发者只设定世界规则和初始状态，小镇居民（Agent）自主感知、决策、学习、传播知识，逐渐形成独特的小镇社会结构。支持玩家以居民身份介入，与Agent共同改变世界。

## 2. 核心目标
- 验证多Agent自主交互、知识自进化的闭环可行性
- 实现可回放、可观察、可干预的小镇模拟系统
- 构建开发者与小镇双向迭代的世界补丁机制

## 3. 非目标（v0.1阶段）
- 不实现1000+ Agent的大规模模拟
- 不实现复杂的3D渲染
- 不实现完全自由生成的剧情
- 不实现强依赖LLM的实时对话系统

## 4. 核心体验
- 观察小镇居民每天的生活、工作、社交、学习
- 看到知识在Agent之间的传播、演变、冲突、固化
- 作为新居民加入小镇，影响事件发展
- 查看任意一天的小镇历史，回放发展过程

## 5. v0.1验收标准
1. ✅ 2D小镇地图，10个Agent，3个地点，5种事件类型
2. ✅ Agent能自主移动、工作、观察、记录知识、传播传闻
3. ✅ 所有行为写入事件日志，支持按日期查询
4. ✅ 知识系统支持结构化存储、传播、质疑、修正
5. ✅ 玩家可以制造事件并被Agent观察到
6. ✅ 网页控制台支持实时查看小镇状态、每日摘要、历史记录
7. ✅ 每天自动生成中文详细行为摘要

## 6. 风险与应对
- **风险1**：Agent行为过于重复，缺乏多样性
  - 应对：引入随机事件、性格差异、动态目标系统
- **风险2**：知识系统过于复杂，难以维护
  - 应对：先实现模板化知识生成，后续迭代自由生成
- **风险3**：性能问题，Tick速度过慢
  - 应对：大部分行为使用规则引擎，仅关键决策调用LLM

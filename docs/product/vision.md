# K-town 产品愿景

**版本**: v0.1 草稿
**最后更新**: 2026-08-02

## 1. 长期愿景

K-town 是一款多智能体小镇模拟游戏。小镇居民是独立的 AI 智能体，拥有持久的记忆、知识、目标和社会关系。小镇是一个活的系统：环境产生事件，智能体感知事件，知识通过观察和社会传播演化，小镇随时间积累自己的历史、文化和组织。

**核心理念**：游戏的价值不在于"屏幕上 1000 个 LLM NPC 聊天"，而在于"一个能通过智能体行为不断积累知识、关系和历史的小镇系统"。

## 2. 非目标（v0.1 及近期）

- 不是传统 RPG，没有任务、等级或主线剧情。
- 不是到处聊天的系统，每个智能体不会持续调用 LLM。
- 不是城市建设游戏，玩家不直接控制基础设施。
- 不是竞技多人游戏。
- 不是照片级写实 3D 世界。

## 3. 核心体验

### 作为开发者 / 观察者
1. 设计世界规则（地点、资源、事件种子、智能体原型）。
2. 观察小镇演化：智能体过自己的生活、传播知识、形成团体、创造新物品。
3. 通过世界补丁干预，而非编写脚本故事。

### 作为玩家
1. 从 2D 地图俯视观察小镇。
2. 以人类居民身份进入，与智能体互动。
3. 影响一个事件（例如：传播谣言、制作物品、提出新规则）。
4. 观察智能体的反应和小镇的变化。

## 4. 关键风险

| 风险 | 缓解措施 |
|------|---------|
| LLM 成本过高 | 分层智能体运行：冷（仅日程）、温（规则+偶尔 LLM）、热（面向玩家，更高 LLM 频率） |
| 智能体感觉重复/肤浅 | 结构化记忆 + 知识演化 + 持久目标 |
| 系统边界不清晰 | 从 v0.1 最小闭环开始，再扩展 |
| 看不到进展 | 从第一天开始记录一切；尽早构建回放/调试工具 |

## 5. 成功标准 (v0.1)

- [ ] Godot 渲染 2D 地图（地点 + 智能体精灵）。
- [ ] Go 服务器运行 tick 循环驱动智能体状态机。
- [ ] 10 个智能体遵循日常日程并对事件做出反应。
- [ ] 智能体观察事件并生成 `KnowledgeClaim` 记录。
- [ ] 相邻的两个智能体可以对话并传播知识。
- [ ] 玩家可以进入小镇并影响一个事件。
- [ ] 所有行为被记录；查看器可以回放小镇的一天。

## 0. 一句话

**K-town 是一座住着人的手绘小镇，不是一张带图标的仪表盘。**
观察者第一眼应该看到"生活"，第二眼才看到"界面"。

## 1. 风格锚点

### 1.1 现状盘点（2026-08-20）

| 资产 | 现状 | 问题 |
|---|---|---|
| 设计令牌 | 完整：暖色 palette + 4 套时段主题变量（style-v2.css） | 无材质/纹理层，纯色块 |
| SVG 地图 | 像素风（crispEdges 方块建筑）1200×720 | 与"水彩 UI"混搭；无道路；居民=圆点+emoji |
| 图标 | emoji 单一来源 `icons.js` | 全是 emoji，无统一图形语言 |
| 动效 | 粒子/天气/呼吸/昼夜动画**已写好但未触发**（polish-v2.css） | 写了等于没写 |

### 1.2 调和路线：**水彩基调软化像素**

不推翻重做，而是"以水彩为基底，让像素建筑长出手绘的灵魂"：

| 维度 | 水彩（UI 基调） | 像素（地图基调） | 调和方案 |
|---|---|---|---|
| 边缘 | 柔和、有晕染 | crispEdges 硬边 | 建筑外轮廓保留像素感，加 1px 手绘抖动描边；地面/道路用水彩渐变而非纯色块 |
| 色彩 | 暖色系 50-700 阶 | 高饱和纯色 | 地图取色全部走令牌色（--earth/green/sky 系），禁止裸色值 |
| 光影 | 无 | 硬阴影 | 建筑加手绘柔影（低透明度错位色块），傍晚/夜间的窗户透出暖光 |
| 材质 | 纯色 | 纯色 | 用 SVG 噪点滤镜（feTurbulence）给地面/墙壁加纸面颗粒感 |

### 1.3 禁止项（风格红线）

- ❌ 裸色值（所有颜色必须来自令牌，新增令牌需评审）
- ❌ 又加一套新的"赛博/扁平/Material"风格（保持暖色手绘）
- ❌ 居民继续用"纯圆点+emoji"（必须升级为像素小人，见 §3.2）
- ❌ 半途而废的动效（要么接上 JS 触发，要么删除，见 §4）

## 3. 地图升级规格（SVG 1200×720）

### 3.1 道路（当前是空注释，`town-map-v2.js:138`）

- **必要**：连接 5 地点（广场/工坊/荒野/学校/矿洞）的土路。
- 画法：`<path>` 手绘曲线（二次贝塞尔），`stroke=earth-300`，`stroke-width=18`，`stroke-linecap=round`，下层叠 24px earth-200 做边缘，中间叠 10px 沙色做"走出来的路"。
- 沿路点缀：小石子、脚印（可选动画：傍晚收工时人流沿路移动）。

### 3.2 居民形象（当前是圆点+emoji，`town-map-v2.js:290-293`）

**像素小人替代圆点**：8×8 级像素小人（参照 stardew 比例）：
- 头（肤色 4×4）+ 身体（职业色 4×6，`AGENT_COLORS` 复用）+ 腿（2px）。
- 表情仍是情绪信号：头上一枚小 emoji（😊😐😠😟😔）悬浮，替代现在脸上的 emoji。
- 光环保留（情绪色 aura）但改为更柔和的 radial gradient。
- 名字标签保留（hover 才显示，减少常驻遮挡）。

### 3.3 建筑细节（`drawPixelBuilding` 已参数化 variant/color）

- 现有变体保留（金字塔顶/钟楼/烟囱/矿洞拱门），各补：
  - 傍晚/夜间窗内暖光（`--window-glow`，随时段切换）
  - 门前小物：花盆/木箱/招牌（每建筑 1-2 件，手绘抖动）
  - 阴影：建筑右下错位 3px 半透明色块（手绘柔影）

### 3.4 天气与昼夜（复用现有动画资产）

- 现有：雨/雪/云/风粒子、天空渐变、月亮、昼夜遮罩——**全部接上 JS 触发**（见 §4）。

## 4. 动效接入清单（"写了等于没写"的修复）

`polish-v2.css` 已有实现但无 JS 引用，全部接入：

| 资产 | 现状 | 接入点 |
|---|---|---|
| 粒子 canvas（萤火虫/落叶/飞鸟） | 无 JS | `app-v2.js` 按天气/时段初始化 canvas |
| 震屏 | 无 JS | 灾害事件时对地图容器加 class |
| 人物呼吸/弹跳 | 部分 | 常驻呼吸 + 移动时弹跳 |
| 天气（雨雪风） | 无 JS | 天气状态切换时驱动 |
| 昼夜渐变 | 有 | 保留 |
| 低性能模式 | 无 JS | 检测 `prefers-reduced-motion` + 帧率降级 |
| 色盲模式 | 无 JS | 保留开关，地图加色盲安全色 |

> **原则**：动效是"叙事的一部分"，不是装饰。一次灾害的震屏+雨点+红色警告，比三个数值变化更有游戏感。

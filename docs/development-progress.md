## 关键决策

| 决策 | 理由 | 日期 |
|------|------|------|
| v0.1 使用内存存储 | 设置更简单；持久化是 v1 的事 | 2026-08-02 |
| Agent 默认基于规则；LLM 在功能标志后 | 成本控制；LLM 仅用于关键决策 | 2026-05-28 |
| Go 服务器 + Godot 客户端 | 服务器性能，客户端快速迭代 | 2026-05-28 |
| WebSocket 实时同步 | 低延迟；Go 和 Godot 都支持好 | 2026-05-28 |

# K-town v0.1 世界观设定

## 1. 背景故事
K-town 是一座刚建立的边境小镇，位于森林与山脉之间的谷地。镇民来自不同的地方，他们不知道这个地方的全貌，需要共同探索、建设、形成自己的社会秩序。

## 2. 地点设定（v0.1包含3个地点）
### 2.1 广场（square）
- **功能**：公共集会、信息交流、商业交易
- **可观察信息**：公告栏信息、在场居民、交易价格
- **可执行动作**：发布公告、聊天、交易、集会
- **规则**：每天早晨6点更新公告，交易价格随供需变化

### 2.2 工坊（workshop）
- **功能**：制作工具、加工材料、技术研发
- **可观察信息**：当前加工物品、材料库存、工匠技能
- **可执行动作**：制作工具、改良技术、教学
- **规则**：制作工具需要消耗材料和体力，技能越高产出越好

### 2.3 荒野（wilderness）
- **功能**：采集资源、探索未知、发现新知识
- **可观察信息**：资源分布、危险程度、探索进度
- **可执行动作**：采集食物、探索区域、绘制地图
- **规则**：探索有概率遇到危险，也可能发现新资源点

## 3. 资源类型
- **食物**：维持Agent体力，每天消耗1单位
- **材料**：用于制作工具，荒野采集获得
- **金币**：通用货币，通过工作、交易获得
- **知识**：通过观察、学习、交流获得，影响Agent能力

## 4. 事件类型（v0.1包含5种）
1. **天气变化**：影响所有地点的工作效率
2. **资源发现**：荒野出现新的资源点
3. **社交相遇**：两个Agent在同一地点相遇，可能传播知识
4. **物品制作**：工坊制作出新物品
5. **传闻传播**：Agent之间传播一条知识或传闻

# K-town v0.1 开发计划

## 目标
实现K-town v0.1原型，包含10个Agent、3个地点、5种事件类型，支持知识自进化、每日摘要、历史回放功能。

## 任务拆分
### 阶段1：基础框架搭建
- [x] 创建项目结构，删除Go代码，独立Python项目
- [x] 编写所有设计文档（PRD、世界观、Agent模型、知识系统、架构）
- [ ] 实现核心数据模型（models.py）
- [ ] 实现配置加载模块（config.py）
- [ ] 实现数据库持久化模块（db.py）

### 阶段2：世界系统实现
- [ ] 实现世界状态管理（world.py）
- [ ] 实现天气系统，支持天气变化影响工作效率
- [ ] 实现地点系统，支持地点属性和规则
- [ ] 实现资源系统，支持资源采集和消耗

### 阶段3：事件系统实现
- [ ] 实现事件总线（events.py）
- [ ] 实现5种基础事件类型
- [ ] 实现事件调度器，生成日常和随机事件
- [ ] 实现事件处理逻辑

### 阶段4：Agent系统实现
- [ ] 实现Agent核心类（agent.py）
- [ ] 实现Agent感知、思考、决策、行动流程
- [ ] 实现10种职业Agent的初始化和行为逻辑
- [ ] 实现Agent状态管理（体力、心情、金币、位置）
- [ ] 实现Agent记忆系统（短期、长期、日记）
- [ ] 实现Agent目标系统

### 阶段5：知识系统实现
- [ ] 实现知识引擎（knowledge.py）
- [ ] 实现知识创建、传播、质疑、修正、固化流程
- [ ] 实现知识冲突解决机制
- [ ] 实现知识查询接口

### 阶段6：Tick引擎实现
- [ ] 实现Tick循环引擎（tick.py）
- [ ] 实现每日摘要生成逻辑，支持中文详细描述
- [ ] 实现实时事件推送逻辑
- [ ] 实现历史数据保存逻辑

### 阶段7：API和前端实现
- [ ] 实现REST API接口（api.py）
- [ ] 实现WebSocket实时推送
- [ ] 实现前端界面（templates/index.html）
- [ ] 实现实时状态展示、Agent状态、每日摘要、历史查询功能
- [ ] 美化前端界面，实现城市天际线风格

### 阶段8：测试和优化
- [ ] 测试所有功能是否正常运行
- [ ] 优化性能，确保Tick速度稳定
- [ ] 修复所有已知问题
- [ ] 完善文档

## 验收标准
1. 所有代码通过语法检查，无错误
2. 服务器可以正常启动，端口8090
3. 前端界面正常显示，所有数据实时更新
4. 每天自动生成中文每日摘要
5. 历史数据可以正常查询
6. 所有Agent按照规则自主行动
7. 知识系统正常运行，支持传播和演变

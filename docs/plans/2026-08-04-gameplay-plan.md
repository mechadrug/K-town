## 1. 功能安排（按优先级）

### P0 —— 修复与体验成立（v0.4 交付）

#### F0.1 图标系统统一（修 `?`）
- **为何**：index-v2.html 图标 emoji 在编码转换中丢失 + app-v2.js 字面量 `??` 占位符。
- **做什么**：新建 `static/icons.js` 单一 emoji 映射表；全站图标引用它；清空所有字面量 `?`；动态文本统一 `textContent`。
- **文件**：`static/icons.js`(新)、`templates/index-v2.html`、`static/app-v2.js`、`static/town-map-v2.js`
- **验收**：全界面无 `?`、无乱码、图标来源单一。

#### F0.2 Tab 显示修复（知识/任务真实显示）
- **为何**：`tab-panel` 内联 `style="display:none"` 覆盖 `.active` class → 知识/任务 Tab 永不显示。
- **做什么**：`switchTab()` 显式设置每个面板 `style.display`；移除对 `.active` class 的依赖；初始加载即拉取知识/任务数据（而非切 Tab 才拉）。
- **文件**：`static/app-v2.js`、`static/panels-v2.css`
- **验收**：三个 Tab 可切换；任务/知识列表真实渲染（非"暂无"）。

#### F0.3 对话系统重设计（修"聊天意义不明"）
- **为何**：对话是通用罐头，无语境、无门控、无后果。
- **做什么**：按设计 §4.2 重写 `DialogueSystem`——话题由（性格×心情×关系×今日事件）生成；选项随关系门控；每次对话产生可见后果（好感±/知识交换/心情微调）；对话写入行为日志进日报。
- **文件**：`dialogue.py`、`api.py`（/api/dialogue/* 返回语境字段）、`static/app-v2.js`
- **验收**：与不同 Agent 对话内容不同；对话后好感/知识/心情真实变化；日报提到"你与 X 交谈"。

#### F0.4 交互模型统一（修"点头像也能对话"）
- **为何**：档案既是"看"又是"聊"入口，按钮重叠。
- **做什么**：点居民 → 只开档案；档案内一个 [交谈] 按钮；行动栏 [聊天] = 与当前地点一位居民对话；删除重复入口。
- **文件**：`templates/index-v2.html`、`static/app-v2.js`、`static/town-map-v2.js`
- **验收**：交互只有一条路径；无歧义入口。

#### F0.5 小镇脉搏首屏（信息架构）
- **为何**：当前第一屏是玩家数值，小镇脉搏被挤到角落（与"小镇是主角"相反）。
- **做什么**：侧栏第一块改为"小镇脉搏"（在场者/心情分布/正在传的知识/最新事件）；玩家数值收敛为顶栏小 pill。
- **文件**：`templates/index-v2.html`、`static/app-v2.js`、`static/style-v2.css`
- **验收**：打开页面第一眼看到的是小镇的生活而非玩家资源。

#### F0.6 每日目标薄层
- **为何**：任务引擎空转，任务 Tab 无内容。
- **做什么**：每日从"可执行动作"池生成 3 目标（采集2次/交谈2人/赚20金/调查1次/传知识1条）；进度挂在 `_handle_action` 实时推进；完成发放奖励（金币/好感）。
- **文件**：`quests.py`、`tick.py`、`api.py`、`static/app-v2.js`
- **验收**：玩家动作真实推进目标进度；完成有奖励；任务 Tab 实时显示进度。

#### F0.7 知识流动视图（招牌可视化）
- **为何**：知识是 K-town 招牌，但当前只是静态置信度列表。
- **做什么**：知识视图改为"谁信了什么 → 传给谁 → 置信度涨跌 → 冲突/固化"的流动视图（卡片式时间线即可，无需图算法）。
- **文件**：`static/app-v2.js`、`api.py`（/api/knowledge 补 created_by/传播路径/冲突关系）
- **验收**：能看到一条知识从产生到传播到固化的轨迹。

#### F0.8 每日领悟（知识即记忆）
- **为何**：把"知识"从旁观资料升级为**主角寻回记忆的核心机制**（承接失忆主线）。
- **做什么**：每日可提交 1 次思考（0 AP，随时可提交）；若文本触及隐藏剧情关键词（遗迹/石碑/十三/玉佩/地球/时间/转速/黑夜/文明/秘密…），封印松动 → **领悟技能 + 想起记忆碎片**（写入日记/日报）。
- **文件**：`tick.py`（INSIGHT_TOPICS + `_check_insight`）、`api.py`（add_claim 每日限次 + 领悟触发）、`static/app-v2.js`（按钮当日禁用/日重置）、`templates/index-v2.html`（tooltip/引导）
- **验收**：每日只能提交 1 次；提交"遗迹"等关键词获得技能与记忆碎片；知识与伏笔形成闭环。

## 4. 当前前端四类问题的根因速查（实现时对照）

| 现象 | 根因 | 修法 |
|---|---|---|
| 一堆 `?` | GBK→UTF-8 丢失 + 字面量占位符 | icons.js 统一来源 + 清占位符 |
| 知识/任务不显示 | 内联 `display:none` 覆盖 `.active` | switchTab 显式驱动 display |
| 聊天意义不明 | 罐头回复无语境/后果 | dialogue.py 重设计（设计§4.2） |
| 点头像也能对话 | 入口重叠 | 点人=档案，交谈=唯一动作 |

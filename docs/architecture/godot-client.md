# Godot 客户端

**版本**: v0.1
**最后更新**: 2026-08-02

## 1. 场景结构

主要场景包括：
- 主场景：初始化一切
- 世界地图：2D 地图，包含地点和地形
- 地点：可复用的地点节点（广场、工坊、荒野）
- Agent 精灵：Agent 的视觉表现
- 顶部栏：日期/时间显示、天气、控制
- Agent 查看器：选中 Agent 详情侧面板
- 对话面板：对话查看器
- 事件日志：最近事件滚动列表
- 回放条：回放模式时间轴 scrubber
- 玩家控制器：处理玩家输入和移动

## 2. 关键节点

### TownMap（Node2D）
- 持有所有地点节点和 Agent 精灵
- 处理摄像机平移/缩放
- 接收 StateDelta 消息并更新位置

### AgentSprite（Node2D）
- 显示 Agent 外观（简单圆形/图标 + 名称标签）
- 按角色或心情颜色编码
- 点击打开查看器
- 在地点间移动时动画

### AgentInspector（Panel）
- 显示选中 Agent 的身份、状态和目标
- 列出最近记忆和关键知识声明
- 允许玩家互动（对话、交易、给予物品）

## 3. 网络

使用 WebSocket 连接到 Go 服务器。
- 连接时：接收完整世界状态快照
- 游戏期间：接收增量（仅变化部分）
- 玩家动作：发送给服务器，等待下一个增量

## 4. 输入处理

| 输入 | 动作 |
|------|------|
| 方向键 / WASD | 玩家在地点间移动 |
| 点击 Agent | 打开查看器 |
| 点击地点 | 移动到该地点 |
| 空格 | 与地点互动 |
| Tab | 切换事件日志面板 |
| R | 切换回放模式 |

## 5. 渲染风格

- **视角**：2D 俯视
- **美术风格**：简洁、干净、暖色调
- **Agent**：圆形 + 角色图标 + 名称标签
- **地点**：不同颜色区域 + 简单图标
- **天气**：叠加效果（雨滴粒子、云层着色）

## 6. 回放模式

- 用 R 键切换
- 屏幕底部显示时间轴
- 拖动到任意过去 tick 查看当时小镇状态
- 速度控制：0.5x、1x、2x、4x
- 数据源：服务器事件日志

## 7. v0.1 简化

- 无自定义美术：使用 Godot 内置形状和字体
- 单屏 UI（无场景切换）
- 玩家始终可见；3 个地点无需滚动摄像机
- 对话纯文本（无语音）

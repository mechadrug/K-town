# 日志与回放系统

**版本**: v0.1
**最后更新**: 2026-08-02

## 1. 为何记录一切

每个 Agent 决策、世界事件和知识变化都被记录。这些日志服务于：
- **小镇报纸**：自动生成的每日摘要
- **Agent 日记**：每个 Agent 的个人记录
- **开发者调试**：理解 Agent 为何做某事
- **回放查看器**：回顾小镇历史
- **AI 上下文**：未来会话可读取日志

## 2. 日志类型

### 2.1 世界事件日志
记录世界中发生的所有事件，包括 tick、事件类型、地点、涉及 Actor 和载荷。

### 2.2 Agent 决策日志
记录每个 Agent 的决策和原因，包括 tick、Agent ID、动作、原因、目标、置信度和方法。

### 2.3 知识变化日志
记录所有声明变异，包括 tick、声明 ID、Agent ID、操作类型、变化前后。

## 3. 日志存储（v0.1）

内存环形缓冲区（可配置容量，默认 10000 条）。日志也作为 JSON 行写入 stdout 供外部收集。

## 4. 查询接口

- GET /api/logs/world - 按 tick 范围和地点查询
- GET /api/logs/decisions - 按 Agent ID 查询
- GET /api/logs/knowledge - 按声明 ID 查询
- GET /api/logs/timeline?day=1 - 查询指定日期所有日志

## 5. 回放系统

### 5.1 回放数据
回放是从日志重建的世界状态序列：初始状态 + 事件增量 = 任何未来状态。

### 5.2 回放流程
客户端请求 tick 范围内的日志并可视化重建。

### 5.3 回放控制
- **拖动**：拖动到加载范围内的任意 tick
- **单步前进/后退**：单 tick 推进
- **播放/暂停**：按选定速度自动推进
- **速度**：0.5x、1x、2x、4x

## 6. 未来增强

- **持久日志存储**：PostgreSQL 长期保留
- **日志压缩**：压缩旧 tick，保留近期详细记录
- **热力图**：可视化 Agent 移动模式、知识传播
- **报纸生成器**：LLM 将每日事件总结为可读文章
- **冲突亮点**：标记有趣决策点供开发者查看
